# Commandes de base

- `pwd` : chemin absolu
- `cd` : changer de répertoire
- `ls` : lister
  - `-l` : détails
  - `-a` : fichiers cachés
  - `-F` : type
  - `-R` : récursif
  - `-t` : tri par date
- `mkdir` : créer un dossier
- `rmdir` : supprimer un dossier vide
- `man` : consulter l'aide
- `history` : historique des commandes
