# 1. Цель работы

Познакомиться с менеджером паролей `pass` и системой управления файлами конфигурации `chezmoi`. Научиться устанавливать, настраивать и использовать эти инструменты для безопасного хранения паролей и синхронизации dotfiles.

# 2. Задание

1. Установить менеджер паролей `pass` и настроить его (создать GPG-ключ, инициализировать хранилище, добавить пароли).
2. Установить `chezmoi` для управления конфигурационными файлами, создать репозиторий dotfiles и применить его.
3. Освоить основные команды `pass` (insert, show, generate, git push/pull).
4. Освоить основные команды `chezmoi` (init, diff, apply, update).
