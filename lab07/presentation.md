# Цель

- Ознакомиться с файловой системой Linux
- Освоить команды для работы с файлами и каталогами

# Основные команды

| Команда | Назначение |
|---------|------------|
| `touch` | Создание пустого файла |
| `cat` | Просмотр содержимого |
| `less` | Постраничный просмотр |
| `head` / `tail` | Первые/последние строки |
| `cp` | Копирование |
| `mv` | Перемещение/переименование |
| `chmod` | Изменение прав доступа |

# Права доступа

- `r` – чтение
- `w` – запись
- `x` – выполнение
- `u` – владелец
- `g` – группа
- `o` – остальные

# Анализ ФС

- `mount` – смонтированные ФС
- `df -h` – использование диска
- `du -sh` – размер каталога
